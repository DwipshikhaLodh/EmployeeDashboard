# EmployeeDashboard

This project was created using [Angular CLI](https://github.com/angular/angular-cli) version 20.0.1. and CSS.

### Features
* Dashboard Home - We see details as Employees count & Department count.
* Dashboard Employees - Add new Employees, Edit and Delete existing Employees.
* We can Search by Name or Email, Sort by Name or Date of Joining & Filter by Department.
* The application is responsive in mobile view as well.

### Bonus Feature
* We can export the Employees List as CSV.
* We can toggle the mode by clicking on toggle button present on Topbar.
* Dashboard Home - We can see overall details as - Department count & Employees count.

## Branch to clone
"develop" branch has the complete code of Employee Dashboard Application.

## Development server

To start a local development server, run:
* After cloning the 
```bash
npm install
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.

## Building

To build the project run:

```bash
ng build
```

This will compile your project and store the build artifacts in the `dist/` directory. By default, the production build optimizes your application for performance and speed.
